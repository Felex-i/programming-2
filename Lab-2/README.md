## Задание
Написать функцию `add(nums, target)`, которая принимает массив целых
чисел и целевое число, и возвращает индексы двух элементов массива,
в сумме дающих `target`. Один и тот же элемент нельзя использовать дважды.

# Сумма двух: тесты для функции `add(nums, target)`

Тесты лежат в `test_add.py`, запуск: `python -m unittest -v`.
Функция может вернуть индексы в любом порядке и любую подходящую пару,
поэтому в тестах везде перечислены все допустимые ответы.

## Группы ситуаций

1. **Обычные случаи:** пример из шаблона, несколько подходящих пар.
2. **Повторяющиеся значения:** одинаковые числа в списке, один и тот же элемент нельзя брать дважды.
3. **Особые числа:** отрицательные числа и нули.
4. **Расположение пары:** пара стоит в самом конце списка.
5. **Пары нет:** подходящей суммы нет, список пустой, в списке один элемент.
6. **Побочные эффекты:** функция не должна менять переданный список.

## Ошибки

| Тест | Какую ошибку может найти |
|---|---|
| `test_basic_case` | функция вообще не работает или возвращает не те индексы |
| `test_same_element_not_used_twice` | один элемент берётся два раза |
| `test_equal_values` | одинаковые числа теряются |
| `test_no_pair` | вместо `None` возвращается что-то другое (`[]`, `False`) или происходит ошибка |
| `test_empty_list` | ошибка при пустом списке |
| `test_one_element` | элемент складывается сам с собой, хотя пары нет |
| `test_negative_numbers` | функция рассчитана только на положительные числа |
| `test_zeros` | нули пропускаются |
| `test_pair_at_the_end` | ошибка в границах цикла: последний элемент не проверяется |
| `test_several_pairs` | функция ошибается, когда подходящих пар несколько |
| `test_list_not_changed` | функция сортирует или меняет переданный список |

## Разнообразный набор 
Каждый тест проверяет свою ситуацию, а не повторяет одно и то же с другими числами:
обычные и крайние случаи, особые числа, отсутствие ответа и неизменность входных данных.
