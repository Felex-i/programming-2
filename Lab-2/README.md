# Лабораторная работа №1. Сумма двух

**Автор:** Ерохина Анастасия, ИВТ-2(1)

## Задание
Написать функцию `add(nums, target)`, которая принимает массив целых
чисел и целевое число, и возвращает индексы двух элементов массива,
в сумме дающих `target`. Один и тот же элемент нельзя использовать дважды.
